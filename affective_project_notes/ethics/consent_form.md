# Consent form for text-message ratings

## Purpose

This course project studies how a rule-based customer-support assistant
estimates the emotion expressed in short NovaShop messages and chooses a
support action. Ratings are used to compare the system with human judgments.

## What participation involves

- You will read fictional customer-support messages, with earlier turns from
  the same conversation shown as context.
- You will rate each message on 9-point valence/pleasure, arousal/activity,
  and dominance/control scales, select an emotion label and a suitable support
  action, and may enter an optional comment.
- No engine predictions are shown during rating.
- Please do not include your own name, contact details, account details, or
  other personal information in comments.

## Data, privacy, and withdrawal

- Ratings are saved using an anonymous rater ID. The tool does not ask for a
  participant name or contact information.
- Ratings and optional comments are stored locally in
  `engine/evaluation/ratings/<rater-id>.csv`.
